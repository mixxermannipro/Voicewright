# Beitragen

Lege für deine Änderung einen eigenen Zweig auf Basis von `main` an.
Beschreibe im Pull Request (Änderungsvorschlag auf GitHub), welchen Ablauf
du geändert hast. Nenne Betriebssystem, Tests und offene Prüfungen.

- Voraussetzungen und Startbefehle stehen in der [Installationsanleitung](docs/INSTALLATION.md).
- Nutze die [Testanleitung](docs/TESTING.md) für die lokalen Prüfungen.
- Liefere für behobene Fehler möglichst einen Test, der den Fehler reproduziert.
- Nutze eigene oder passend lizenzierte Testdaten. Gib die Herkunft an.
- Aktualisiere Deutsch und Englisch, wenn du sichtbare Texte änderst.

Melde mögliche Sicherheitslücken über den Weg in [SECURITY.md](SECURITY.md).
