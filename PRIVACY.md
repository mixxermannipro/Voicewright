# Privacy / Datenschutz

Voicewright processes microphone audio locally with Whisper. Model downloads connect to Hugging Face. With cloud cleanup enabled, recognized text is sent to the chosen provider. Local history is optional. API keys are stored in the system keyring. Finished dictations go to the system clipboard.

Voicewright verarbeitet Mikrofonaufnahmen lokal mit Whisper. Sprachmodelle lädt die App von Hugging Face. Bei aktivierter Cloud-Korrektur sendet sie den erkannten Text an den gewählten Anbieter. Der lokale Verlauf ist optional. API-Schlüssel liegen im System-Schlüsselbund. Fertige Diktate landen in der Systemzwischenablage.
